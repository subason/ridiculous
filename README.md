## ⚙️ 4. Technical Architecture & Stack

- **Framework**: Angular 18+ (Standalone Components, Signals, Computed Signals)
- **Styling**: Pure Modern CSS3 (Glassmorphism, CSS Grid, Custom Properties, `@keyframes`)
- **Charts**: Chart.js 4+ with dynamic dark mode palette switching
- **Confetti Engine**: Native HTML5 Canvas particle physics system
- **Sound Synth**: Web Audio API `AudioContext`
- **Responsive Engine**: Mobile-first media queries (`@media (max-width: 768px)`, `@media (max-width: 1100px)`)

## 🚀 5. Getting Started & Local Setup Guide

### 1. Clone & Install
```bash
cd ridiculous-kpi-dashboard
npm install
```

### 2. Start Local Development Server
```bash
npm start
# OR
npx ng serve --port 4200
```
Open your browser at `http://localhost:4200` (or `http://localhost:32837`).

### 3. Open on Mobile Phone via Wi-Fi
To view the dashboard on your phone or tablet tomorrow:
```bash
npx ng serve --host 0.0.0.0 --port 4200
```
Then navigate on your mobile browser to:
`http://192.168.1.16:4200`
